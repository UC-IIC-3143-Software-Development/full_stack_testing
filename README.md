# Full Stack Testing con IA y DevSecOps

Proyecto de ejemplo de la clase de IIC3143 Desarrollo de Software (UC). Monorepo con
**NestJS + PostgreSQL** (backend), **Next.js** (frontend) y un pipeline de CI con
pruebas en todas las capas y seguridad integrada. Basado en *Full Stack Testing*
(Gayathri Mohan, 2.ª ed., O'Reilly 2026).
